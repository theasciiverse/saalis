# Saalis

Flight, combat, trading and missions in the Northern Reach, the cold,
high fringe of the asteroid belt. An Asciiverse game for the terminal,
in Rust and Ratatui.

**Not playable yet:** design only. See `ROADMAP.md`.

*Saalis* is Finnish for catch, prey, loot: the trader's catch and the
raider's plunder.
